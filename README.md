# Overhaul

Фан-проект по Tanki Online. Браузерный клиент на TypeScript и Three.js, игровой сервер на Node.js и MariaDB. Клиент и сервер хранятся вместе, поскольку используют один протокол и общую физику.

## Сборка и тесты

Требуются Node.js 24 и pnpm 11.25.0. Эти команды выполняются в корне репозитория и доступны без пакета игровых ресурсов.

```bash
pnpm --dir html5 install --frozen-lockfile
pnpm --dir html5 build
node server2/build.mjs
node tools/test-source.mjs
```

Те же проверки запускает GitHub Actions. Серверный сборщик использует TypeScript и esbuild из зависимостей клиента. Собранный `server2/dist/server2.mjs` совместим с Node.js 18, в том числе на старом Debian.

## Запуск отдельной облачной копии

1. Скачайте архив ресурсов из [релиза runtime-v1](https://github.com/slavadech91/resources-project-tank/releases/tag/runtime-v1) и распакуйте его в корень клона. Он добавляет `dev/configs` и `html5/public`. Извлекайте его до сборки клиента, чтобы Vite перенёс ресурсы в `html5/dist`.
2. Создайте отдельную базу MariaDB и пользователя с доступом к ней. Сервер использует `mysql_native_password`. Примените `server2/deploy/schema.sql` к новой базе. Таблицы боёв, заданий и вариантов внешнего вида сервер создаёт при запуске.
3. Передайте серверу настройки базы через переменные `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD` и `DB_NAME` средствами секретов хостинга. Конфигурация по умолчанию использует базу `overhaul` на `127.0.0.1:3306`.

```bash
curl -fL -o overhaul-runtime.tar.gz https://github.com/slavadech91/resources-project-tank/releases/download/runtime-v1/overhaul-runtime.tar.gz
tar -xzf overhaul-runtime.tar.gz
mariadb -h 127.0.0.1 -u overhaul -p overhaul < server2/deploy/schema.sql
pnpm --dir html5 build
node server2/build.mjs
TANKI_DEV="$PWD/dev" HOST=127.0.0.1 PORT=5290 node server2/dist/server2.mjs
```

В другом процессе из того же корня запустите веб-сервер.

```bash
HOST=127.0.0.1 PORT=5180 SERVER2_PORT=5290 node html5/server/public-server.mjs
```

Клиент открывается на `http://127.0.0.1:5180/`. Для внешнего доступа настройте прокси с HTTPS и поддержкой WebSocket на `/ws2`. Диагностика игрового сервера доступна по `http://127.0.0.1:5290/health`. Локальный режим разработки запускается командой `pnpm --dir html5 dev` с тем же игровым сервером на порту 5290.

## Что передать в облако

- Клонируйте этот репозиторий исходников в облачное рабочее окружение.
- Скачайте архив ресурсов из релиза GitHub. Он содержит игровые ассеты, необходимые для запуска, и настройки без учётных данных. Для обновления архива с рабочего дерева есть `tools/package-runtime.py`. Для текущего набора карт передайте `--exclude-map test --exclude-map polygon`.
- Базу существующих игроков, приватные ключи и параметры рабочего сервера храните отдельно. Пустой тестовой копии достаточно схемы MariaDB и собственного пароля.

## Обновление установленного Overhaul на Debian

После каждого успешного коммита в `main` GitHub Actions публикует готовую сборку клиента и сервера в Releases с тегом `debian-<commit-sha>`. На Debian, под пользователем, которому принадлежит `~/project-overhaul`, один раз установите скрипт.

```bash
mkdir -p ~/.local/bin
curl -fsSL https://raw.githubusercontent.com/slavadech91/resources-project-tank/main/tools/update-debian.sh -o ~/.local/bin/overhaul-update
chmod +x ~/.local/bin/overhaul-update
```

Для установки свежей сборки запустите `~/.local/bin/overhaul-update`. Можно передать конкретный тег Debian. Флаг `--check` скачивает и проверяет пакет без установки. Скрипт подготавливает файлы до остановки служб. После переключения он проверяет HTTP клиента и сервера и при ошибке восстанавливает предыдущую сборку. Активные бои прерываются на время перезапуска.

Обновление рассчитано на существующую установку с Node.js 18, рабочими службами `tanki-overhaul-server2` и `tanki-overhaul-web` и правом вызвать `sudo -n systemctl`. База, `dev/configs` и игровые ресурсы берутся из текущей установки. Изменения карт, текстур или конфигов из отдельного runtime-релиза устанавливаются отдельно.

## Ориентиры для разработки

- `html5/src/net2` содержит протокол и клиентские обработчики. `server2/src/handlers.ts` содержит серверные обработчики.
- `server2/src/battle` содержит бой, CTF, бонусы, оружие и ботов. `server2/data/bot-navigation.json` содержит заранее рассчитанные графы навигации. При изменении коллизий карты пересоберите их командой `node --experimental-transform-types server2/tools/export-bot-navigation.ts` с установленным пакетом ресурсов.
- `html5/src/ui` содержит лобби, гараж, чат, окно заданий и боевой интерфейс.
- Перенесены Изиду и другие пушки, боты с разными корпусами и оружием, командное поведение, бой для новичков на «Песочнице», ежедневные задания и интерфейс челленджей. Серверная часть челленджей пока отсутствует.
- Пакет содержит семь карт с доступными клиентскими ресурсами. Служебная карта `test` исключена: в рабочей сборке у неё отсутствуют файлы карты для браузера. «Полигон» из Diamond ещё не подключён. Найденный «Полигон» Narukami имеет собственные геометрию и зоны дропа.

## Источники

Игровые ресурсы относятся к Tanki Online и использованным фан-сборкам. В исходниках и при переносе использовались материалы Narukami, Diamond of Tanki, ProTankiClientRemake, ReTankiOnline и TO-Assets. Существующие указания авторства и лицензий сохранены, в частности отметка об AGPL-3.0-or-later для использованного серверного кода Narukami. В работе над проектом участвовали ИИ-агенты.
