# TDM, сообщения и CTF (server2), 05.11.2026

Источник интерфейса и правил клиента: juhe1/ProtankiClientRemake, commit `4510ded2156640e1f7f0715032a0dd993e191f5b`. Читаемые файлы сохранены в `assets/protanki_remake_src/Code/src/alternativa/tanks/models/`.

- `TeamScoreFieldBase`, `TDMScoreField`, `ComplexTeamScoreIndicator`, `FlagIndicator`: рамка WhiteFrame снизу справа, шрифт 18, исходные красный/синий градиент и цвета чисел, индикаторы флага (на базе, быстро мигает у носителя, медленно мигает на земле). Прежний верхний счёт скрыт только для server2.
- `BattlefieldMessages`, `Message`: максимум три строки, шаг 18px, без фоновой плашки. Обычная последовательность альфы: 500ms появления, 2000ms полной видимости, 700ms до 0.6, 10000ms удержания, 700ms исчезновения. Уведомление золота и события флагов используют этот канал.
- `CTFModel`, `CTFFlag`: сервер владеет флагами; подбор только активным танком при пересечении габаритов и видимости. Триггер флага 95×95×400; габариты корпуса берутся из текущего loadout. Возврат своего касанием, доставка чужого при своём на базе, сброс F, блок повторного подбора 5000ms. При смерти/выходе носителя флаг сбрасывается; при отсутствии безопасной поверхности возвращается. Командные убийства не дают флаговых очков. Достижение лимита доставок завершает раунд; новый раунд обнуляет командный счёт и флаги.

Координаты из `<ctf-flags>` в XML карт; начало флага на 80cm выше поверхности пьедестала (`Z_DISPLACEMENT`). CTF включён скриптом `tools/enable_ctf_maps.py` в src/dev только для карт с базами: test, Тишина, Серпухов. Арена баз не имеет. Существующие характеристики оружия, корпусов и лимиты из server_properties не изменены.

Ресурсы: HUD и восемь значков действий — из `_assets` того же commit. Флаги, 3ds-пьедесталы и четыре звука — terminal-cs/TO-Assets/Battle/Modes/CTF. Экспорт `tools/export_protanki_battle_ui.py`; 3ds переводятся в локальные координаты, UV сохраняются. Текущий TO-Assets содержит одиночные изображения флагов, поэтому покадрового колыхания нет. У своего носителя флаг полупрозрачен и привязан к `fmnt` башни.

ProtankiClientRemake — клиент, его репозиторий не определяет серверный таймер автоматического возврата. Здесь принято 30 секунд (адаптация, не подтверждённое значение из его серверных исходников). Боты могут взаимодействовать с флагом касанием, но отдельного стратегического AI для CTF этот перенос не добавляет.

Офлайн: `server2/tools/ctf-unit.ts` проверяет состояния, препятствия, команды, захват, сброс/блокировку, смерть, возврат по таймеру, снимок входящего игрока, исходные базы и связь Battle с командным счётом/концом раунда. Также пройдены typecheck html5/server2 и проверки bots/thunder/killfeed/gold-drop/damage-display. Проверку в реальном бою выполняет пользователь.
