# Gen 2 / Old в гараже и бою, 06.11.2026

## Пользовательский выбор

Кнопка «Улучшить» временно открывает окно оформления с превью Gen 2 и Old. Выбор бесплатный, общий для M0–M3 одной пушки/корпуса, сохраняется в аккаунте и не меняет покупку/установку/микроулучшения. Доступен и для предпросмотра предмета магазина. Большое превью, карточки списка и картинка описания используют выбранный комплект. Бой получает вариант при следующем входе; его видят все игроки. Это HTML5/server2, Flash-протокол не расширялся.

Девять пушек: Смоки, Твинс, Огнемёт, Рельса, Изида, Гром, Фриз, Рикошет, Шафт. Семь оригинальных корпусов: Васп, Хантер, Титан, Диктатор, Хорнет, Викинг, Мамонт. Варан исключён из преобразования и сохраняет свои ресурсы; у него нет исторического Old-набора.

Gen 2 — вариант по умолчанию, включая Гром M0–M3. Причина прежнего вида Грома: add_thunder_item.py первоначально копировал модель/текстуры из assets/models/Flash/Turrets/Old/Thunder. Канонические Flash-файлы не переписывались; новый HTML5-резолвер выбирает отдельный проверенный Gen 2 комплект.

## Ассеты

Источник: terminal-cs/TO-Assets, commit **55f1377054177d1bdaaf19dfae56cb98b02a5303**. `tools/build_cosmetic_variants.py`: фиксирует ревизию, скачивает 794 файла (81.6 MB) в `assets/cosmetic_variants_src`, проверяет Git blob SHA каждого файла, конвертирует родным parse_3ds из convert_tank_parts.py. Псевдонимы архива: frezee → freeze, mamoth → mammoth.

Сборка создаёт 128 визуальных деталей в `html5/public/tank_parts/styles/{gen2,old}/{hulls,turrets}/<name>/mN`, 136 атласов и восемь полос заряда Рельсы в `html5/public/battle/styles/{gen2,old}`, манифест `tank_parts/appearances.json`. Модель и UV берутся из того же набора, что details.png/lightmap.jpg; исходная альфа PNG сохраняется. Это важно: одни Old-текстуры на модели Gen 2 наложились бы неправильно.

Общие следы попаданий, вспомогательные эффекты и звуки, для которых в архиве нет альтернатив, сохраняются исходными общими ресурсами. У корпусов нет отдельных Old-эффектов в источнике: двигатель/смерть остаются общими, окно это сообщает. Шафт имеет одинаковые исходные ресурсы в ряде вариантов — различие не выдумывается. Состав/размеры/альфа/раскладка кадров описаны в MODLOG.md и манифесте. PNG-полосы Smoky без дескрипторов: число близких к квадрату кадров выведено по размерам (Gen2 M0 4592x201 → 23 равные UV-ячейки); сами PNG не масштабируются. Заряд Рельсы использует существующий compositor ChargingTextureRegistry, 210x210x30, со вписыванием слоёв Gen 2 одним масштабированием.

## Механика сохраняется

В part.json отделены `objects` (вид) от `physicalObjects` (канонические объекты текущего проекта), `spec` скопирован без изменений. Bounds, mount, muzzle/fmnt и хитбоксы берутся из canonical. Old-файлы имеют имена Hull/turret_Vol и другие отличия; appearancePhysicsMesh выбирает физический корень по роли, не только точному имени. Геометрия видимых моделей меняется ради правильной UV, подвеска, масса, скорость, урон, отдача и коллизии — нет.

TankDemo загружает эффекты выбранного поколения/модификации. S2Battle передаёт тот же выбор чужим танкам; кеши разделены по поколению, виду пушки и модификации. Исправлен прежний общий кеш Smoky/Twins, который мог бы подставить собственный эффект чужому игроку. Railgun кеширует ресурсные данные по base+mod и создаёт отдельные экземпляры заряда, как прежде. Геометрия/механика выстрелов и потоков сохраняется.

## Сервер

`AppearanceStore` создаёт S2Appearance(user_id,family,style), ключ (user_id,family). Данные читаются при загрузке гаража/входе в бой; дополнительных запросов в физическом тике нет. `garage.appearance` принимает только itemId и enum gen2/old, определяет family по серверному каталогу, userId — из авторизованной сессии. Неподдерживаемые модели/поколения отклоняются. Это предпочтение оформления, не выдача предметов и не обход оплаты.

GarageLists передаёт appearances, loadout включает hullStyle/turretStyle в parts; физические поля не меняются. Снимки движения/боевые команды не расширялись. Конфиги src/dev и баланс не редактировались.
