# Гром — перенос Narukami, 05.11.2026

Источник: локальный `narukami/client/game/src/alternativa/tanks/models/weapon/thunder`, классы ThunderWeapon, ThunderEffects, ThunderShotEffect, SplashModel и SplashParams.

Выстрел использует три screen-спрайта и три треугольных луча, исходные размеры, скорости и срок 50 мс. Для каждой модификации загружаются её текстуры. Разрыв один, в точке контакта со смещением на 1 см по нормали, с отступом к камере 110 см; звук без задержки. След радиусом 250 см ставится только на статике.

Сервер считает сплеш от контакта, исключает прямую цель и проверяет укрытие тремя лучами. Клиент применяет радиальный толчок, включая собственный танк и союзников, с проверкой укрытия. Ослабление по расстоянию действует на прямое попадание и сплеш. Дополнительные взрывы на каждой повреждённой цели убраны.

Текущий баланс M0–M3 сохранён. В наших данных нет отдельного параметра силы сплеша: для физического толчка используется текущая сила попадания и текущая кривая сплеша. AnimatedLightEffect из Narukami пока не перенесён: исходных световых кривых Грома в текущем наборе данных нет.

Экспорт ресурсов: `tools/export_thunder_html5_media.py`. Офлайн-проверка: `server2/tools/thunder-unit.ts` (состав и срок вспышки, привязка к дулу, контактный центр сплеша, укрытие, собственный урон). Проверку в бою выполняет пользователь.
