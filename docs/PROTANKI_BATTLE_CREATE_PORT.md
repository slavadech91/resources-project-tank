## Серверные настройки

Раньше S2Client вообще не передавал флажки формы серверу. Теперь протокол/БД JSON сохраняет и Battle применяет:

- автобаланс входа в команды (не позволяет пополнить уже большую команду), огонь по своим для обычных попаданий/сплеша/мин; союзное убийство не награждается очками и фондом;
- ящики припасов, кристаллы, золото — отдельные переключатели; выключенные золотые ящики не вызывают предупреждений;
- припасы инвентаря, отдельно мины и аптечки; запрет проверяется перед списанием, в HUD запрещённые слоты имеют нулевое доступное количество (склад сохраняется);
- сирена золота: уведомление остаётся, звук зависит от настройки;
- микроулучшения: базовые уровни всех свойств снаряжения при сборке серверного Loadout; значения баланса в конфигах не меняются;
- форматы NONE / Хорнет–Рельса / Васп–Рельса / Хорнет+Васп–Рельса. Снаряжение проверяется до выхода из предыдущего боя. Хорнет–Рельса несовместим с нашими ботами на Васпе;
- приватная битва скрывается из списка и push-обновлений обычных пользователей. `lobby.getBattle` открывает её по ссылке, после чего сессия получает обновления. Администратор видит все. Ссылка не является паролем. Копируется полный URL, есть fallback для HTTP без Clipboard API.

Исходные модификаторы смены снаряжения в бою, точных таймингов, ослабленных резистов, зоны золота, случайного фонда, общей перезарядки, кланов и овердрайвов показаны недоступными с пояснением. Их механика не перенесена, подтверждённых серверных правил для них нет; подмена выдуманными коэффициентами не делалась. Форматы LIGHT/HARD и паркур тоже недоступны. CP не добавлялся. В источнике часть этих флажков/сериализации также закомментирована. Основной рабочий путь — server2 (`?s2`); старый Python/Flash-протокол не расширяли.

## Гараж

Округление только визуальное, в таблице M0–M3 для здоровья/урона (id 1,40,41,45,52,55,58,62), включая диапазоны и дожигание. Скорость, перезарядка, масса, лечение и прочие значения сохраняют прежнюю точность. Баланс не изменён.
